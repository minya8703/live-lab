# JASSO 장학금 시스템 멀티디바이스 리뉴얼

- 기간: 2018.01 ~ 2018.12
- 소속: 스마트아이엔지 → 일본학생지원기구(JASSO)
- 도메인: 일본 공공기관 · 장학금 신청 시스템
- 환경: 폐쇄망

## 기술 스택
Appium (자습), Java, JSP, jQuery, HiRDB, JavaScript

## 배경
전국 학생 대상 장학금 신청 시스템의 PC·태블릿·모바일 화면 대응과 화면 에비던스 검증이 필요했다.

## 핵심 기여
- **PC · 태블릿 · 모바일 3종 디바이스** 화면을 Java/JSP 기반으로 개발
- 화면 에비던스 검증을 위해 Appium 테스트 진행 방법을 자습
- Appium 테스트 진행 방법을 팀 내 표준으로 문서화하고 공유

## 결과
- 멀티디바이스 화면 대응
- Appium 테스트 방법 표준화
