# JASSO 장학금 시스템 멀티디바이스 리뉴얼

- 기간: 2018.01 ~ 2018.12
- 소속: 스마트아이엔지 → 일본학생지원기구(JASSO)
- 도메인: 일본 공공기관 · 장학금 신청 시스템
- 환경: 폐쇄망

## 기술 스택
Appium (자습), Java, JSP, jQuery, HiRDB, JavaScript

## 배경
접속자가 약 170% 증가해 PC·태블릿·모바일 다양한 디바이스 대응 필요. 기존 테스트는 수작업 화면 에비던스 캡처로 시간 소요 과다. 폐쇄망 환경이라 외부 패키지 설치 제한.

## 핵심 기여
- 폐쇄망 환경에서 **Appium 테스트 가능 환경을 처음부터 자체 구성** (자습) — 환경 설정부터 매뉴얼화하여 팀 내 재현 가능한 구조 확립
- 수작업 화면 에비던스 캡처 → Appium 자동화 전환
- **PC · 태블릿 · 모바일 3종 디바이스** 테스트 자동화 환경 구성
- 테스트 자동화 가이드 작성 → 팀 내 지식 공유

## 결과
- 테스트 속도 **100% 향상 (2배)**
- 접속자 **약 170% 증가** 대응 (성능·안정성)
- 멀티디바이스 **20개+** 화면 자동화
