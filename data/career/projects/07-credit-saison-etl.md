# Credit Saison 신용카드 데이터 통합

- 기간: 2013.04 ~ 2014.12
- 소속: 아시아정보시스템 (일본)
- 도메인: 신용카드 회원·결제 데이터 통합

## 기술 스택
Informatica PowerCenter ETL (자습 후 실무 적용), 일본어 마스킹 테스트 데이터 자체 생성

## 핵심 기여
- Informatica PowerCenter를 **자습**해 실무 즉시 적용
- 일본어 마스킹 테스트 데이터 자체 생성 (실데이터 보호)

## 결과
- 회원 데이터 **2,500만 건** 정합성 이슈 **0건**
- 1차 무장애 완료 후 **2차 재투입 인정**
