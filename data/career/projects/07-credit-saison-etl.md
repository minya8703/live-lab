# Credit Saison 신용카드 데이터 통합

- 기간: 2013.04 ~ 2013.09, 2014.01 ~ 2014.12 (1·2차 참여)
- 소속: 아시아정보시스템 → Credit Saison
- 도메인: 신용카드 회원·결제 데이터 통합 (Teradata → Oracle 플랫폼 전환)
- 규모: 사용자 약 2,500만 명

## 기술 스택
Informatica PowerCenter, Oracle, Teradata, PL/SQL, SQL Developer

## 배경
시스템 고도화에 따른 DB 플랫폼 전환 필요. 2,500만 명의 카드 지급·연체 데이터는 단 하나의 오류도 허용되지 않는 환경.

## 핵심 기여
- Informatica PowerCenter를 **매뉴얼 자습**으로 익혀 실무 즉시 적용
- ETL 매핑 설계 과정에서 기본설계·상세설계 불일치 발견 → 담당자와 직접 조율
- **일본어 한자·히라가나 기반 마스킹 테스트 데이터** 자체 생성 (실데이터 보호)
- Oracle DBMS 재설계로 사용자 증가에 따른 성능 저하 해소

## 결과
- 회원 데이터 **2,500만 건 정합성 이슈 0건**
- 1차 무장애 완료 후 **고품질 평가로 2차 재투입**
