# MONEX 증권 MFA 인증 시스템

- 기간: 2021.03 ~ 2021.05
- 소속: 스마트아이엔지 (일본)
- 도메인: 증권 · 인증

## 기술 스택
Java Servlet, Servlet Filter 패턴, SMS 인증, 레거시 시스템 통합

## 핵심 기여
- **Servlet Filter 패턴**으로 레거시 코드 수정 없이 **비침투적 MFA 통합**
- UX 5단계 → 3단계로 축소 설계 (채택됨)

## 결과
- SMS 인증 성공률 **99.2%**
- 도입 후 장애 **0건**
- 2021.09 공식 서비스화
