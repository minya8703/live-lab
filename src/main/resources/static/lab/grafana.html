U6 · 관측성 대시보드

"Prometheus + Grafana로 운영"을 라이브로 증명

Spring Boot Actuator + Micrometer가 노출하는 메트릭을 Prometheus가 5초 간격으로 스크레이프, Grafana가 익명 read-only로 즉시 시각화합니다. 아래 대시보드는 localhost:3001의 실제 Grafana를 iframe으로 임베드한 것이고, 다른 데모 페이지를 여러 번 호출하면 패널이 실시간으로 반응합니다.

새 탭에서 열기 ↗ Prometheus 직접 열기 ↗

대시보드가 안 보이면 — Grafana가 안 떠있거나 (docker compose up -d grafana), 브라우저가 iframe을 차단했을 가능성. 위 "새 탭에서 열기" 버튼으로 동일 화면 확인 가능.

대시보드가 보여주는 6개 패널

  • JVM Heap Used — 영역별 메모리 사용량. 누수·GC 패턴 파악.
  • HTTP Request Rate (per URI) — 엔드포인트별 초당 호출 수. 챗봇/Redis/Kafka API 부하 비교.
  • HikariCP Connections — Active·Idle·Pending. DB 풀 압박 신호.
  • Spring Cache — Hits vs Misses — U4의 캐시 효과를 운영 메트릭으로 재확인.
  • Kafka Consumer Records — U5의 소비 처리량 라이브 추적.
  • HTTP Response Max (per URI) — 엔드포인트별 응답 시간 피크. 지연 spike 감지.

의도적 설계 결정

  • Grafana는 GF_AUTH_ANONYMOUS_ENABLED=true로 익명 Viewer 접근 허용 → 방문자가 로그인 없이 본다.
  • GF_SECURITY_ALLOW_EMBEDDING=true로 iframe 임베드 허용 (기본은 차단).
  • 모든 메트릭에 application=live-lab 태그 → Prometheus 쿼리 격리.
  • 대시보드는 infra/grafana/dashboards/livelab.json으로 코드화. Grafana UI 수동 변경 없이 git으로 관리 (IaC 원칙).
