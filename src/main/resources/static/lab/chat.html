민야령의 경력에 직접 물어보세요

Spring AI 추상화 위 Google Gemini 2.5 Flash. 경력 데이터에 없는 영역은 "없다"고 답하고, 대신 인접 경험과 현재 방향성을 함께 안내합니다.

⚖ 이 챗봇의 trade-off (의식적 선택)

현재단일 LLM (Gemini 2.5 Flash) · 시스템 프롬프트에 경력 마크다운 전체 주입 · 서버가 직접 확인한 peer 주소 기준 1시간 fixed window 20회 제한 · 비활성 bucket 정리.

한계 1프롬프트 규칙만으로 사실성을 보장할 수 없고 출처도 선택 사항 — 실제 파일에 근거한 답변인지 서버가 검증하지 않음.

한계 2호출자가 위조할 수 있는 X-Forwarded-For는 신뢰하지 않는다. 그 대신 Cloudflare 뒤에서는 여러 사용자가 같은 peer 한도를 공유할 수 있으며, fixed window 경계에서 요청이 몰릴 수 있고 현재 상태는 단일 인스턴스 전용이다.

운영급 방향(1) 관련 문서만 선택해 전달. (2) answer/sources/grounded 구조화 응답과 출처 검증. (3) 공격·허위 질문 평가셋을 CI에서 실행. (4) origin을 Cloudflare 대역으로 제한한 뒤 CF-Connecting-IP를 검증해 사용자별 한도 적용. (5) 토큰·지연·실패 메트릭.

현 사이트가 안 가는 이유문서 수가 작아 전체 주입이 아직 단순하고 저렴함. 검색 도입 전 먼저 출처 계약과 평가 기준을 추가할 예정.

안녕하세요. 민야령의 경력 Q&A 챗봇입니다.
